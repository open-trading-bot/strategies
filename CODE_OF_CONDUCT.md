# Code of Conduct

This code applies to the issues, pull requests and other spaces of this project.

## Expected behavior

- Treat all persons with respect.
- Discuss the work, not the person.
- Accept that other persons can have a different opinion.
- Help new contributors.

## Unacceptable behavior

- Harassment, threats or personal attacks.
- Offensive comments about a person or a group of persons.
- Publication of private information about a person without permission.
- Spam, or promotion of signals, paid groups or investment schemes.
- Promises of trading profit.

## Report a problem

To report behavior in this project, use [GitHub's report form](https://github.com/contact/report-abuse).

## What the maintainers can do

The maintainers can edit or remove a comment, close or lock a discussion, and block a user from the project.
